# 🇮🇳 TECC — The Election Campaign Company

### The King Makers

A visually immersive single-page website concept for **The Election Campaign Company (TECC)** — a digital election campaign platform designed around online voter outreach, communication, voter analysis, and campaign management.

The website presents the idea of moving traditional election campaigning into the digital space through a modern, interactive, India-inspired interface.

---

## 📌 About The Project

**The Election Campaign Company (TECC)** is a website concept focused on digital election campaigning.

The project communicates the idea that as communication and voter engagement increasingly move into the digital world, election campaigns can also leverage online platforms to reach and interact with voters.

The website presents TECC as a company that manages the digital side of an election campaign, allowing campaign teams to focus on their broader election activities.

The project combines:

- Modern editorial-style web design
- Indian-inspired visual elements
- Smooth scrolling and parallax animations
- Responsive layouts
- Digital voter communication concepts
- Campaign analytics concepts
- Direct voter interaction
- A clean single-page experience

---

## ✨ Features

### 🎨 Immersive Visual Design

The website uses a visual language inspired by the Indian tricolour:

- Saffron
- White
- Green
- Navy blue

The design uses layered gradients, hills, clouds, glowing elements, and illustrations to create a continuous visual journey throughout the page.

---

### 🌄 Interactive Parallax Hero

The landing section contains a layered sunrise landscape with:

- Animated clouds
- Multiple SVG hill layers
- A glowing sun
- Animated hero text
- Smooth scrolling
- Parallax movement

The different layers move at different speeds to create a sense of depth.

---

### 📱 Digital Campaign Messaging

The website explains the concept of taking election campaigning online and highlights digital voter engagement as a central theme.

The **Why Online** section introduces the shift toward digital communication and social-media-based voter engagement.

---

### 📊 Campaign Services

The project presents several campaign-oriented capabilities:

#### Reach Lakhs With One Click

A campaign application can be used to distribute campaign messages to large audiences.

#### Know Your Voters

The concept includes analysing voter information and providing campaign insights before election results.

#### Multi-Channel Communication

The interface describes communication through:

- Calls
- SMS
- WhatsApp
- Text
- Images
- Videos

#### Voter Location & Navigation

Campaign personnel can be guided toward a voter's location.

#### Direct Voter Communication

The concept allows voters to communicate directly with the campaign and raise issues without necessarily requiring an in-person meeting.

---

## 🌙 Interactive Campaign Section

A full-screen dark section separates the main content from the contact section.

It contains the message:

> **Think bigger. Become bigger.**

The section combines:

- Tricolour-inspired glowing elements
- Floating visual assets
- Smooth parallax movement
- Large editorial typography
- Full-screen presentation

---

## 📩 Contact Section

The website includes direct contact options for TECC through:

- Email
- Telephone

The contact information is presented as interactive links so that users can directly open their email client or initiate a phone call on supported devices.

# 🛠️ Technologies Used

This project is built using standard web technologies without a frontend framework.

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and semantic markup |
| CSS3 | Layout, styling, animations and responsive design |
| JavaScript | Parallax scrolling and interaction |
| SVG | Custom illustrations and decorative elements |
| Google Fonts | Typography |
| Responsive CSS | Mobile and tablet layouts |
